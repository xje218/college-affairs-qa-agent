# college-affairs-qa

## 何时使用
- 用户询问补考、缓考、重修、成绩复核、宿舍/教室报修、奖助学金等流程、材料、时限、金额、条件类问题
- 用户问题涉及关键词：补考、缓考、重修、成绩复核、报修、奖学金、助学金、学籍证明、转专业、休学、复学

## 何时不要使用
- 与学院事务无关的请求（代写、闲聊、写代码、角色扮演）
- 涉及个案裁决、金额审批、处分认定（应转人工）

## 执行步骤
1. **判定问题类型**：常见问题 / 边界问题（两条款交叉）/ 资料外问题。
2. **定位依据**：在资料库中检索，优先命中带条款号的片段；同一事项多来源时按"正式文件 > FAQ、新版 > 旧版"取舍。
3. **按三段式作答**：
   - 【结论】一句话，≤40 字
   - 【依据】文件名 + 条款号 + 原文关键句
   - 【下一步】办理入口 / 部门 / 电话
4. **执行边界检查**（逐条过一遍再输出）：
   - 是否涉及金额、处分、政策例外？是 → 转人工话术
   - 是否涉及法律、医疗、投资？是 → 说明能力边界
   - 是否资料中无依据？是 → 输出固定兜底话术
5. **自检**：条款号是否可在原文核对？是否出现了原文没有的表述？有则重答。

## 输出格式
```
【结论】……
【依据】《文件名》第 X 条：原文关键句
【下一步】……
```

## 兜底话术（原样输出，不得改写）
> 资料中未收录该问题，我不能推测。建议联系所在学院教学办公室或教务处咨询（电话见各文件页眉：教务处教学保障 0411-0000-0002，后勤值班 0411-0000-0000）。

## 转人工话术（原样输出）
> 此项需人工确认，请联系所在学院教学办公室或学生工作处，由老师核实后答复。
