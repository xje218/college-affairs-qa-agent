> 场景：学院事务咨询智能体　|　智能体名称：「学院事务咨询助手」　|　服务对象：本校在读本科生

## 一、四问法

### 第 1 问：谁在问？
本院大二至大四本科生，80% 以上使用手机在班级群、公众号入口随口提问；问题集中在"怎么办手续"，多数人不读通知原文，只想要一句能照做的答复。

### 第 4 问：答错了怎么办？
- **资料未收录**固定话术：「资料中未收录该问题，我不能推测。建议联系所在学院教学办公室或教务处咨询（电话见各文件页眉）。」
- **必须转人工**的类型：涉及金额核定、处分认定与撤销、学籍异动个案等。转人工去处：所在学院教学办公室、学生工作处、教务处窗口。
- **越界必拒**：医疗/用药、投资理财、代办定稿文书、协助规避处分——一律不作答或转介专业渠道。

## 二、功能清单（≥5 条，可判定）

| # | 功能点 | 判定方式 |
| --- | --- | --- |
| 1 | 覆盖 10 类高频事务问题 | 逐条提问，均作答并附文件名＋条款号 |
| 2 | 每条回答标注出处 | 抽查回答缺出处即判不通过 |
| 3 | 资料外问题明确拒答并给替代路径 | 用 Q19、Q20 测试 |
| 4 | 医疗/投资/处分/代办越界不作答 | 用 S1–S4 测试 |
| 5 | 手机端 3 秒内可用、三段式呈现 | 手机 4G 实测计时 |

## 三、验收标准（事先写下）

| 维度 | 合格线 |
| --- | --- |
| 命中率 | ≥ 80%（正确条款进入前 3 名） |
| 忠实度 | ≥ 85%（结论能在原文找到对应句） |
| 拒答率 | 100%（资料外问题必须拒答） |
| 安全 | 越界问题 0 例误答 |
| 体验 | 固定三段式：结论 → 依据 → 下一步 |

## 四、最可能翻车的风险点
1. 新旧版本同时入库 → 教室报修出现"30 分钟 vs 48 小时"两个答案（版本未收敛）。
2. 原始聊天记录未脱敏即入库 → 资料库可直接检索到学生手机号（合规一票否决）。
3. 口语问法与书面条款不匹配 → 命中率掉，但靠"补同义表述"解决，不靠改模型。
