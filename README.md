# 学院事务咨询助手（单人版）

一个面向本校学生的**学院事务咨询智能体**：覆盖补考、缓考、重修、成绩复核、奖助学金、宿舍与教室报修六大类事务。基于现行有效制度文件做确定性检索式问答，每条回答带【结论】【依据】【下一步】三段与条款出处，对资料外问题固定拒答，对医疗/投资/处分/代办类越界问题一律不作答或转介。

> 本仓库为《人工智能工具应用实践》第 10 次课「智能体构建」练习（单人版）的完整交付物，语料为课堂虚构样例。

## 在线试用
打开发布的问答页即可用手机/电脑直接提问（见下方发布的 GitHub Pages 链接）。

## 仓库结构
```
index.html             # 问答页（移动端优先，前端检索式问答）
kb.json               # 知识库：clauses（条款）+ topics（作答主题）+ boundary（边界）+ fallback
使用说明.md            # 适用范围 / 不适用范围 / 如何更新语料
.github/workflows/kb-review.yml   # 资料库月度核对自动化
交付文档/
  ├─ 四问法_需求拆解.md        # 阶段一：需求拆解
  ├─ 语料治理记录.md          # 阶段二：版本收敛 / 冲突 / 脱敏
  ├─ 系统提示词.md            # 阶段五：角色 + 格式 + 边界 + 兜底
  ├─ 测试记录_第1轮.md        # 阶段七：20 题 + 4 安全题测试与三项指标
  ├─ 测试题库与验收记录表_已填写.xlsx   # 逐题记录 + 16 项验收清单（已填）
  ├─ 语料库/                  # 5 份现行有效制度 + 脱敏后的咨询问题频次表
  ├─ 归档/                    # 已废止的 2023 版（移出检索范围）
  └─ .workbuddy/skills/college-affairs-qa/SKILL.md   # 阶段四：技能固化
```

## 本地运行
```
# 需在本地起一个静态服务器（因 fetch kb.json 受 file:// 限制）
python -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

## 说明
- 问答引擎为「主题—条款」确定性检索，与测试脚本 `run_tests.py` 完全同源，保证可复现。
- 如需接入真实大模型，可将 `index.html` 中的 `answer()` 替换为对 LLM API 的调用，仍保留本仓库的边界与兜底约束。
